## 📌 Project Overview

An Excel-based marketplace operations dashboard designed to monitor product catalog health, listing status, content completeness, customer ratings, reviews, and issue resolution.

This project simulates the type of operational tracking used in D2C and e-commerce marketplace environments.

## 🎯 Objective

The objective of this project was to build a centralized system that helps marketplace teams:

* Monitor product listing status
* Identify inactive and suppressed listings
* Track product availability
* Measure listing content completeness
* Monitor ratings and review volume
* Identify catalog and content issues
* Prioritize operational issues
* Track issue resolution
* Generate marketplace health summaries

## 🛠️ Tools Used

* Microsoft Excel
* Excel Formulas
* Pivot-style Summary Tables
* Conditional Formatting
* Data Validation
* Charts & Dashboards
* Data Cleaning & Analysis

## 📊 Key Metrics

The dashboard tracks:

* Total SKUs
* Live Listings
* Inactive Listings
* Suppressed Listings
* Listings with Issues
* Average Product Rating
* Content Completeness
* Open Issues
* In-Progress Issues
* Resolved Issues

## 📁 Workbook Structure

### 1. Product_Data

Contains product-level marketplace information including:

* SKU
* Product name
* Brand
* Category
* Price
* Rating
* Review count
* Availability
* Listing status
* Product title
* Description
* Images
* Bullet points
* Attributes
* Content completeness
* Issue status
* Priority

### 2. Issue_Tracker

Tracks marketplace issues from identification through resolution.

Each issue includes:

* Issue ID
* SKU
* Issue type
* Issue description
* Priority
* Date identified
* Status
* Action required
* Resolution date

### 3. Summary

Provides pivot-style summaries of:

* Listing status
* Issue types
* Issue priorities
* Marketplace KPIs

### 4. Dashboard

Provides a visual overview of marketplace health through KPI cards, charts, and an operational review checklist.

## 🔍 Key Analysis Areas

The project focuses on identifying common marketplace operational problems such as:

* Inactive listings
* Suppressed listings
* Missing product information
* Incomplete content
* Out-of-stock products
* Low product ratings
* Catalog inconsistencies
* Unresolved marketplace issues

## 💡 Business Use Case

A marketplace operations team can use a similar system to regularly audit product catalogs, prioritize listing issues, monitor customer feedback, and track issue resolution.
